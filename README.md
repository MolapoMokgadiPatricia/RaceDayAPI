## RaceDay API
RaceDay API is a RESTful Web API engineered as an event management backend system supporting road running, walking, and cycling events across South Africa. The system delivers a secure, role-based architecture allowing administrators/organisers to manage multi-category events and capture athletic results, while enabling participants to register, track personal profile data, and check official race scores.
The platform is built using ASP.NET Core 8, Entity Framework Core 8, and Microsoft SQL Server, featuring secure session-based cookie authentication and automated evaluation.


## Technology Stack
• Backend Framework: ASP.NET Core 8.0 Web API

• Programming Language: C# 12

• Database Engine: Microsoft SQL Server

• ORM Mapping: Entity Framework Core 8 (Code-First Strategy)

• Identity Management: Session-Based Cookie State Infrastructure

• API Metrics / UI: Swagger Tooling / OpenAPI Specification

• Testing Engine: xUnit Test Framework

• CI/CD Lifecycle: GitHub Actions Pipelines

• Source Tracking: Git & GitHub
